# StudentSurvivalKit

A desktop application for international students to manage documents,
deadlines, job applications, expenses, housing, courses, health records,
and contacts — all in one place.

## Tech Stack
- Java 17 + Swing
- MySQL 8.0
- JDBC
- MVC Architecture

## Database
10 tables: Student, Document, Deadline, JobApplication,
Expense, Housing, Course, HealthRecord, Contact, Recruiter

## Setup
1. Run `sql/schema.sql` in MySQL Workbench
2. Create `src/db/db.properties` with your MySQL credentials
3. Open project in IntelliJ and run `Main.java`
